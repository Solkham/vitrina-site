# Витрина

Маркетплейс одежды из Ингушетии. Главная страница — дворцовый зал, где у каждого магазина своя каталка с вещами.

Сайт: https://vitrina-ingushetia.netlify.app

## Что читать
- [PLAN.md](PLAN.md) — текущий план: кино-вступление по скроллу и новый вид зала. Раскадровка, дизайн, шаги, риски.
- [CLAUDE.md](CLAUDE.md) — как устроен зал сейчас.
- [PLAN-arhiv-2026-10-realizm-zala.md](PLAN-arhiv-2026-10-realizm-zala.md) — прошлый, закрытый этап.

## Запуск
```
npm install
npm run dev
```

Стек: Vite, чистый JS, GSAP, Supabase.
